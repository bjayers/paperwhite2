# To check and to add

The user's checklist for the ecological encounters after the first generation (2026-11-12): the weather that the
encounters wait on or would use, and the cave and building maps whose depth decides where older stages live. Tick
items off or note the answers here; the cloud session then changes the dictionary and reruns
`tools/generate.py --install`. `weather.md` has the full weather plan this is drawn from.
